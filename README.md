# ライフプランニング逆算電卓

「今の給料でどう暮らすか」ではなく、「どう生きたいか」から出発して、必要な年収・貯蓄・投資額を逆算する単一HTMLの電卓ツールです。

## 使い方

`index.html` をブラウザで直接開くだけで動作します。ビルドやサーバーは不要です。

1. 年齢を入力してテンプレート(堅実 / 標準 / 都心共働き)を選ぶと、結婚・出産などのタイミングが年齢に合わせて自動調整され、すぐに結果が表示されます
2. 住居・家族構成・教育・老後・投資前提の各ステップで、スライダーやフォームを使って自分の理想に合わせて調整します(金額は万円単位で入力)
3. 「結果」では、この暮らしに必要な年収を筆頭に、支出の内訳、どの選択が必要額を押し上げているかの分析、年収推移、純資産シミュレーションを確認できます

主な機能:

- **必要年収の逆算**: 現在とピーク時(子の大学入学期など)の必要年収と、現在の年収でのカバー率ゲージを表示
- **毎月の家計イメージ**: 手取り月収・生活費・住居費・教育費・必要積立を毎月のお財布の形で表示
- **次のアクション**: 積立設定・年収アップ目安・理想の調整ポイントなど、結果から逆算した具体的な次の一手を提案
- **積立が「備え」に育つ物語**: 運用益が積立を追い越す年、積立を"卒業"できる年(Coast FIRE)、貯金だけの場合との比較、昇給による負担率の低下をマイルストーンとして表示
- **押し上げ要因の分析**: 各選択(私立進学、都心居住、老後のゆとりなど)を質素な基準に戻した場合との差分を表示
- **積立額のお試し**: 「実際に積み立てる額」スライダーで、必要額に届かない場合に何歳で資産が尽きるかを確認
- **詳細設定**: 昇給率の織り込み、子供ごと・学校段階ごとの公立/私立選択(大学は進学しない選択も可)
- **シナリオ保存・比較**: 「東京私立プラン vs 地方公立プラン」のような複数案の比較
- **共有リンク**: 入力内容をURLに埋め込んで共有

入力内容はブラウザの `localStorage` に自動保存されます。

## 算出方法の要約

- 参照データ(教育費・老後生活費・年金・家賃など)はすべて「現在」の値として保持し、各年の名目値は `基準値 × (1+インフレ率)^経過年数` で算出します。
- テンプレートの昇給率は年2%を初期値としています(国税庁の年齢階層別平均給与カーブの年率換算に基づく目安。詳細設定で変更可)。
- 割引・複利計算は常に「想定運用利回り」で行い、インフレ率と二重計上しないようにしています。
- 生涯資金ギャップは、黒字年・赤字年を通算した生涯純キャッシュフローの現在価値から、現在の貯蓄額を差し引いて算出します。
- 必要な月次投資額は、上記ギャップを埋めるための定額積立(年次複利の年金現価方式)として逆算しています。
- 算出した投資額で積み立てた場合の資産残高をシミュレーションし、計画期間末(100歳)で残高がほぼ0に収束することを内部的に確認しています(整合性チェック)。

## データ出典

文部科学省・日本政策金融公庫・生命保険文化センター・厚生労働省・日本銀行・GPIF・金融庁・国税庁・総務省の公表データを使用しています。詳細は `index.html` フッターの「データ出典」を参照してください。

## 要検証・目安値として扱っている項目

以下は公的な相場データを直接取得できなかったため、ユーザー入力または目安値としています。今後より正確なデータが見つかれば差し替えを推奨します。

- 住宅購入価格(地域・広さ別の相場データ未収録。ユーザー入力必須)
- 結婚費用(本ツールでは計算に含めていません。必要であれば貯蓄額の調整で反映してください)
- 単身者の老後生活費(生命保険文化センターの数値は夫婦世帯のみのため、夫婦データをそのまま使用しています)
- 「高校入学〜大学卒業」の教育費目安(日本政策金融公庫の942.5万円という調査値と、本ツールが文科省データを積み上げて算出する金額(概算660万円程度)は、調査対象・集計範囲が異なるため一致しません。本ツールはMEXT・JFCの個別データをそのまま積み上げる方式を採用しており、目安として参照してください)
